# lesson-02

Учебное мобильное приложение на **React Native (Expo)** и **TypeScript**.
Сделано как набор экранов авторизации: вход, регистрация, подтверждение кода, выбор города и восстановление пароля.

## Как запустить

```
npm install
npx expo start
```

Затем нажмите **a**, чтобы открыть приложение в Android-эмуляторе, или отсканируйте QR-код в Expo Go на телефоне.

## Структура проекта

```
lesson-02
├── App.tsx            # точка входа, собирает экраны приложения
├── index.ts           # регистрация корневого компонента
├── assets/            # иконки и изображения
└── src
    ├── components/    # переиспользуемые компоненты
    │   ├── Header.tsx         # заголовок экрана с кнопкой «назад»
    │   ├── InputField.tsx     # поле ввода
    │   └── PrimaryButton.tsx  # основная кнопка
    ├── screens/       # экраны приложения
    │   ├── LoginScreen.tsx           # вход
    │   ├── RegisterScreen.tsx        # регистрация
    │   ├── VerifyScreen.tsx          # ввод кода подтверждения
    │   ├── CityScreen.tsx            # выбор города
    │   ├── ForgotPasswordScreen.tsx  # «забыли пароль»
    │   └── ResetPasswordScreen.tsx   # новый пароль
    ├── theme.ts       # единые цвета приложения
    └── types.ts       # общие типы TypeScript
```

## Как устроен код

- **Экраны** лежат в `src/screens`, у каждого экрана свой файл.
- **Компоненты** (`Header`, `InputField`, `PrimaryButton`) используются на разных экранах, поэтому код не дублируется.
- `Header` принимает параметры (props): `title` (заголовок), `subtitle` (необязательный подзаголовок) и `onBack` (функция для кнопки «назад»).
- **Цвета** хранятся в `theme.ts`, чтобы менять оформление в одном месте.
- **Стили** задаются через `StyleSheet.create` в каждом файле.
